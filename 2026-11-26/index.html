Lead story · OpenAI · Maths

OpenAI claims the matrix multiplication exponent is exactly 9/4

How fast can two big matrices be multiplied? That limit, the exponent ω, has been chipped away at for more than 50 years. An upper bound of 9/4 (2.25) was already known: the paper credits an earlier OpenAI preprint and Amanov, van den Berg and Zuiddam. OpenAI's new paper, dated 24 Nov, claims the matching lower bound: at every size n ≥ 2, a formal arithmetic circuit needs at least ⌈n9/4/2⌉ multiplication or division gates. That would make the exponent exactly 9/4 over every field.

The Lean formalisation proves the result for division-free circuits. The paper's theorem also allows division gates. An independent open audit by Carlos Toledo declared the Lean statement "CERTIFIED" on 25 Nov, but it notes that nothing has been refereed.

AnthropicEngineeringResearch

Anthropic moves its Messages API to Rust, with Claude agents checking parity

API traffic grew about 1,800× from early 2024 to fall 2026. Claude wrote a first Rust version of the core request path in about a week. Anthropic then ran it against production traffic, found where it differed from the Python version, and automatically sent Claude agents to fix the gaps. The new API uses about 70% less CPU per request and cuts median time to first token by about 20%, with no downtime.

Also new: Anthropic Fellows research, Returning to the neuron basis, argues that individual neurons are more readable, and more useful for safety, than earlier work assumed.
